# Datos Crudos: Cardiotocografía (Fetal Health)

## 1. Procedencia
* **Dataset:** Cardiotocography Data Set
* **Institución de Origen:** Faculdade de Medicina do Porto & Instituto de Engenharia Biomédica (INEB), Porto, Portugal.
* **Repositorio Primario:** UCI Machine Learning Repository / Kaggle.
* **Enlace de Descarga:** [UCI Cardiotocography en Kaggle](https://www.kaggle.com/datasets/propanon/uci-cardiotocography)
* **Formato Original:** `CTG.xls` (2,126 instancias, 40 atributos).

## 2. Política
Este directorio contiene la materia prima sin procesar. Las transformaciones, imputación de nulos y estandarizaciones guardarán en `data/processed/`.
