# Prevención de Mortalidad Fetal e Hipoxia mediante Machine Learning 

##  Descripción del Proyecto
Este proyecto integrador desarrolla un modelo de clasificación multiclase para categorizar exámenes de cardiotocografía (frecuencia cardíaca fetal y contracciones uterinas) en tres estados clínicos: **Normal, Sospechoso y Patológico**. El objetivo es proveer una herramienta de triaje automático para prevenir hipoxia y mortalidad fetal.
